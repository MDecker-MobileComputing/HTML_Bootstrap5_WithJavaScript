Canvas Element and Bootstrap 5

The HTML5 canvas element can be used to draw different geometric shapes.

  • Diagonals
  • Triangle
  • Rectangle
  • Circle
  • Ellipse
  • Bézier curve
  • Pie chart
  • Bar chart
  • Line chart
This option naturally applies only to shapes that form a closed area, e.g. circles or ellipses. The option is only considered when shapes are selected again.
Your browser does not support the HTML5 canvas element (drawing surface).
